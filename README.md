# DannyImageScrubber
Image Scrubber
DannyMediaScrubber

An image sorting with a view window utility built with Python, PyQt6, and VLC. Load a playlist of images, preview them, and quickly move them into organized destination folders or a Recycle bin for later deletion.

Features

Image view window, folders—Dir 1, Dir 2, and send to Recycle bin button.  Auto rename on file conflict .

Requirements

Python 3.x PyQt6 python-vlc send2trash VLC media player installed

Run from source

pip install PyQt6 python-vlc send2trash python main.py
